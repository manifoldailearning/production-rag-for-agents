# Support Escalation Rules

Internal. Support staff only.

Escalate every Enterprise ticket to the customer's technical account manager within 1 hour. Escalate any ticket that mentions data loss as a SEV1 candidate to the on-call engineer immediately.

Billing disputes above $5,000 go to the finance team.
