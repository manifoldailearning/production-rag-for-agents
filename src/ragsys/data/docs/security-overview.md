# Security Overview

All data in transit is encrypted with TLS 1.2 or higher. Buffers and logs are encrypted at rest with AES-256.

Larkspur Cloud holds a SOC 2 Type II report, renewed every year. Customers can request the report under a non-disclosure agreement through their account manager.

Workspace Owners can enforce single sign-on and require two-factor authentication for all members. Audit logs record every configuration change.

Report suspected vulnerabilities to security@larkspur.example.
