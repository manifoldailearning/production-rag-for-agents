# Connector Catalog

Sources: PostgreSQL, MySQL, Salesforce, Stripe, Amazon S3 and Google Sheets.

Destinations: Snowflake, BigQuery, Amazon Redshift and Databricks.

The Salesforce and Stripe connectors require the Team plan or higher. All other connectors are available on every plan.

Each pipeline has exactly one source and one destination.
