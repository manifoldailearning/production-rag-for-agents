# Managing API Keys

API keys authenticate calls to the Larkspur Cloud REST API. Each workspace can have up to 10 active keys.

To rotate a key, open Settings, then API keys, and choose Rotate next to the key. Rotation creates a new key immediately. The old key keeps working for 24 hours so that you can update your systems, and then it is revoked.

To revoke a key immediately, choose Revoke. Revocation cannot be undone.

Never share an API key in a support ticket. Larkspur staff will never ask for your key.
