# Exporting Workspace Configuration

Owners and Admins can export the configuration of every pipeline, connector and schedule in a workspace.

Open Settings, then Workspace, then Export. The export is produced as a ZIP file of JSON documents and is usually ready within one hour. A download link is sent by email and expires after 7 days.

Exports do not include credentials. After importing a configuration into another workspace, you must reauthorize each connector.
